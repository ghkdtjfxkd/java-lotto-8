# java-lotto-precourse

## 입력
- [x] 사용자에게 입력을 받는다.
  - 구매 금액 입력 메시지 : 구입금액을 입력해 주세요.
  - 당첨 번호 입력 메시지 : 당첨 번호를 입력해 주세요.
  - 보너스 번호 입력 메시지 : 보너스 번호를 입력해 주세요.

## 구매
- [x] 구매 내역을 생성한다.

## 로또
- [ ] 번호를 생성한다.

## 일치 여부 확인
- [ ] 숫자 일치 여부를 확인한다.
- [ ] 확인 결과를 반환한다.

## 결과
- [ ] 당첨금을 계산한다.
- [ ] 수익률을 계산한다.

## 출력
- [ ] 구매한 로또 내역을 출력한다.
- [ ] 당첨 내역을 출력한다.
- [ ] 수익률을 출력한다.
  - 수익률은 소수점 둘째 자리에서 반올림한다. (ex. 100.0%, 51.5%, 1,000,000.0%)
- [ ] 에러 문구를 출력한다.
  - 에러 문구는 "[ERROR]"로 시작해야 한다.
